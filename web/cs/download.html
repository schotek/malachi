Stažení

Aktuální verze je 0.1.2, vydaná 26. října 2026. Binárky má zatím jen Linux; aplikace pro macOS a Windows se stavějí ze zdrojů, dokud nebudou podepsané.

K dispozici

Linux

x86_64 a aarch64. Flatpak, nebo nativní balíček pro distribuci s libadwaita 1.7 nebo novější.

  • Flatpak, x86_64 · aarch64
  • .deb, amd64 · arm64
  • .rpm, x86_64 · aarch64

Soubory každé verze zůstávají na stránce vydání.

Ze zdrojů

macOS

macOS 14 nebo novější, Apple silicon i Intel. Aplikace je napsaná ve Swiftu a AppKitu a jádro nese s sebou.

Univerzální obraz disku se staví na každém tagu verze a zveřejní se, až bude podepsaný Developer ID a notarizovaný, což čeká na členství projektu v Apple Developer Programu. Do té doby ho sestavíte ze zdrojů za pár minut.

Ze zdrojů

Windows

Windows 11, x64 i ARM64. Aplikace je napsaná v C# a WinUI 3 a jádro nese s sebou.

Adresář aplikace, který sestavení vytvoří, je nepodepsaný a bez instalátoru; jeho předávání dál čeká na licenční rozhodnutí o komponentách Microsoftu, které nese. Do té doby ho sestavíte ze zdrojů.

Sestavit na Windows

Flatpak

Na Flathubu zatím není. Stáhněte balík pro svou architekturu a nainstalujte ho; runtime GNOME 48 si stáhne z Flathubu.

flatpak install --user ./malachi-0.1.2-x86_64.flatpak

Ubuntu už Flatpak nedodává, takže napřed jeden krok navíc:

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

Flatpak je sestavení, které se aktualizuje samo: nainstalujte přes něj novější balík a data zůstanou. Poskytovatel ChatGPT pro asistenta není ve Flatpaku k dispozici.

.deb a .rpm

Nativní balíčky linkují systémové GTK 4, libadwaitu a WebKitGTK místo vlastního runtimu, a proto potřebují libadwaita 1.7 nebo novější: Ubuntu 26.04 LTS, Debian 14 a Fedora 42, ale ne Ubuntu 24.04 LTS, které má libadwaitu 1.5. Na 24.04 vezměte Flatpak.

sudo apt install ./malachi_0.1.2-1_amd64.deb      # Debian, Ubuntu
sudo dnf install ./malachi-0.1.2-1.fc42.x86_64.rpm   # Fedora

Repozitář pro apt ani dnf neexistuje, takže takto nainstalovaný balíček apt upgrade ani dnf upgrade neaktualizuje. Na rozdíl od Flatpaku dají tyto balíčky malachi-mcp na PATH, což klient MCP potřebuje, aby ho spustil.

Kde leží vaše data

Pošta, nastavení a místní úložiště leží v adresáři aplikačních dat platformy: ~/.local/share/malachi na Linuxu (u Flatpaku v jeho sandboxu), ~/Library/Application Support/Malachi Mail na macOS, %LOCALAPPDATA%\Malachi Mail na Windows. Hesla jsou v systémové klíčence. Nikam jinam než na vaše servery se nic neposílá.

Ze zdrojů

Repozitář se staví na všech třech platformách: Go 1.25 a GTK 4.18 pro linuxového klienta, Swift 6 z Xcode na macOS 14, .NET 10 SDK na Windows 11. Postup pro každou platformu je v návodu na sestavení.

Raná verze. 0.1.2 čte, píše a odesílá poštu na skutečných účtech každý den, ale je to pořád raná verze. Na cokoli důležitého si nechte druhý poštovní program a před aktualizací si přečtěte novinky.
