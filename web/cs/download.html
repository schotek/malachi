Flatpak

Na Flathubu zatím není. Stáhněte balík pro svou architekturu a nainstalujte ho; runtime GNOME 48 si stáhne z Flathubu.

flatpak install --user ./Malachi-Mail-0.4.0-linux-x64.flatpak

Ubuntu už Flatpak nedodává, takže napřed jeden krok navíc:

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

Flatpak je sestavení, které se aktualizuje samo: nainstalujte přes něj novější balík a data zůstanou. Poskytovatel ChatGPT pro asistenta není ve Flatpaku k dispozici.

.deb a .rpm

Nativní balíčky linkují systémové GTK 4, libadwaitu a WebKitGTK místo vlastního runtimu, a proto potřebují libadwaita 1.7 nebo novější: Ubuntu 26.04 LTS, Debian 14 a Fedora 42, ale ne Ubuntu 24.04 LTS, které má libadwaitu 1.5. Na 24.04 vezměte Flatpak.

sudo apt install ./Malachi-Mail-0.4.0-linux-x64.deb            # Debian, Ubuntu
sudo dnf install ./Malachi-Mail-0.4.0-linux-x64-fedora42.rpm   # Fedora

Repozitář pro apt ani dnf neexistuje, takže takto nainstalovaný balíček apt upgrade ani dnf upgrade neaktualizuje. Na rozdíl od Flatpaku dají tyto balíčky malachi-mcp na PATH, což klient MCP potřebuje, aby ho spustil.

Windows

Vezměte instalátor pro svůj procesor: x64 pro většinu počítačů, ARM64 pro Windows na Arm (Snapdragon a podobné). Nainstaluje Malachi Mail do vašeho uživatelského účtu bez práv správce a přidá ho do nabídky Start; odinstalujete ho v Nastavení → Aplikace. Instalátor zatím není podepsaný, takže poprvé SmartScreen hlásí, že ochránil váš počítač: zvolte Další informace a Přesto spustit.

Kde leží vaše data

Pošta, nastavení a místní úložiště leží v adresáři aplikačních dat platformy: ~/.local/share/malachi na Linuxu (u Flatpaku v jeho sandboxu), ~/Library/Application Support/Malachi Mail na macOS, %LOCALAPPDATA%\Malachi Mail na Windows. Hesla jsou v systémové klíčence. Nikam jinam než na vaše servery se nic neposílá.

Ze zdrojů

Repozitář se staví na všech třech platformách: Go 1.25 a GTK 4.18 pro linuxového klienta, Swift 6 z Xcode na macOS 14, .NET 10 SDK na Windows 11. Postup pro každou platformu je v návodu na sestavení.

Raná verze. 0.4.0 čte, píše a odesílá poštu na skutečných účtech každý den, ale je to pořád raná verze. Na cokoli důležitého si nechte druhý poštovní program a před aktualizací si přečtěte novinky.
